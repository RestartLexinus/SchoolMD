## Краткая выжимка

* **Словарь** (`dict`) хранит пары «ключ → значение»: `{"name": "КиберКот", "strength": 85}`
* Значение находят по ключу, а не по номеру: `hero["name"]`
* `d.get(key, default)` не падает при отсутствии ключа, а возвращает `None` или заглушку
* `d[key] = value` добавляет пару или перезаписывает значение: ключи уникальны
* `del d[key]`, `d.pop(key)` и `d.clear()` удаляют пары, `d.setdefault(key, default)` создаёт пару один раз
* `d.items()` перебирает пары, `len(d)` считает их, `key in d` проверяет ключ
* `d1 | d2` объединяет словари (Python 3.9+), `d1.update(d2)` меняет первый на месте

## Что нужно знать заранее

Понадобятся списки из статьи [«Списки»](005_Python_List.md) и цикл `for` из [«Циклов»](003_Python_Циклы.md): словарь, как и список, хранит много элементов, а перебирают его тем же `for`.

```python
heroes = ["КиберКот", "Феникс"]
for hero in heroes:
    print(hero)
```

```text
КиберКот
Феникс
```

Разница только в доступе: в списке элемент ищут по номеру, в словаре — по названию.

> Не помнишь, как работает `for`? Вернись к [003](003_Python_Циклы.md) — это 10 минут.

## 3. Зачем нужен словарь

Список хорош, когда элементы идут по порядку. Но у героя нет «первой характеристики»: у него есть имя, сила и ловкость. Если хранить их в списке, придётся помнить, что `0` — это сила, а `1` — ловкость: перепутал номер — получил не то значение.

**Словарь** — это шкаф с подписанными полками: на полке значение, на дверце имя ключа, поэтому нужную полку называют по имени и перепутать не могут.

```python
hero = {"name": "КиберКот", "strength": 85}
villain = dict(name="Доктор Хаос", threat=10)
villain["powers"] = ["телепортация"]

print(hero["name"])
print(hero.get("wallet", 0))
print(len(villain))
print(villain)
```

```text
КиберКот
0
3
{'name': 'Доктор Хаос', 'threat': 10, 'powers': ['телепортация']}
```

`hero` и `villain` — словари из пар «ключ → значение»: ключи в кавычках, значения любые, даже списки. Квадратные скобки находят значение, а `get("wallet", 0)` при отсутствии ключа вернул `0`. Пустой `{}` заполняют по одной паре, как `villain["powers"]`; `dict(name=...)` — короткая запись для строковых ключей. `len(d)` считает пары, порядок пар сохраняется с Python 3.7.

## 4. Доступ и изменение

Синтаксис один: `d[key] = value`. Если ключ уже был, значение затрётся — ключи уникальны. `del` удаляет пару, `pop()` удаляет и возвращает значение, `setdefault()` создаёт его только один раз, `in` проверяет ключ.

```python
hero = {"name": "КиберКот", "strength": 85}

hero["strength"] = 95
hero["artifact"] = "Кольцо всевидения"
print(hero.pop("artifact"))
print(hero.setdefault("level", 1))
print(hero.setdefault("level", 99))
print("wallet" in hero)
print(hero)
```

```text
Кольцо всевидения
1
1
False
{'name': 'КиберКот', 'strength': 95, 'level': 1}
```

Второй `setdefault` вернул снова `1`: ключ `level` уже существовал, а `99` проигнорировался. Так удобно заводить счётчики и поля, которых может не быть. `in` проверяет **ключи**, а не значения: `95 in hero` дало бы `False`, хотя `95` в словаре лежит.

## 5. Перебор и вложенность

`for key in d` даёт ключи, `d.items()` — пары сразу, `d.values()` — значения. Значением может быть и другой словарь: так хранят записи с полями.

```python
hero = {"name": "КиберКот", "strength": 85}

for key, value in hero.items():
    print(f"{key}: {value}")

achievements = {
    "first_step": {"title": "Новичок", "reward": 100},
    "sword_master": {"title": "Мастер клинка", "reward": 500},
}
achievements["sword_master"]["done"] = True
print(achievements["first_step"]["title"])
print(achievements["sword_master"])
```

```text
name: КиберКот
strength: 85
Новичок
{'title': 'Мастер клинка', 'reward': 500, 'done': True}
```

**Вложенные словари** читаются слева направо: `achievements["first_step"]` — внутренний словарь, `["title"]` — его значение. Новую запись добавляют одной парой: `achievements["no_damage"] = {"title": "Неуязвимый"}`. `keys()`, `values()` и `items()` возвращают не список, а «окно» в словарь: если нужен список, оберните в `list(...)`.

## 6. Объединение словарей

Два словаря склеиваются оператором `|` (Python 3.9+). При совпадении ключей побеждает значение из правого словаря: числа не складываются. `update()` делает то же самое, но меняет словарь на месте.

```python
stock = {"яблоки": 10, "бананы": 5}
delivery = {"бананы": 7, "хлеб": 4}

print(stock | delivery)
stock.update(delivery)
print(stock)
```

```text
{'яблоки': 10, 'бананы': 7, 'хлеб': 4}
{'яблоки': 10, 'бананы': 7, 'хлеб': 4}
```

Бананов стало `7`, а не `12`: правое значение заменило левое. Исходный `stock` после `|` не изменился, потому что оператор создаёт новый словарь. Чтобы **сложить** количества одинаковых товаров, нужен цикл по поставке — это задача из практики ниже.

## 7. Справочник

| Что | Как | Пример | Результат |
|---|---|---|---|
| Создать словарь | `{ключ: значение, ...}` | `{"a": 1, "b": 2}` | две пары |
| Создать через `dict` | `dict(a=1, b=2)` | `dict(name="Кот")` | `{'name': 'Кот'}` |
| Получить значение | `d[key]` | `hero["name"]` | значение, иначе `KeyError` |
| Безопасно получить | `d.get(key, default)` | `hero.get("wallet", 0)` | `0` |
| Добавить или изменить | `d[key] = value` | `hero["strength"] = 95` | пара обновлена |
| Создать, если нет | `d.setdefault(key, default)` | `hero.setdefault("level", 1)` | текущее или новое |
| Проверить ключ | `key in d` | `"name" in hero` | `True` или `False` |
| Сколько пар | `len(d)` | `len(hero)` | `2` |
| Удалить и очистить | `del d[key]`, `d.pop(key)`, `d.clear()` | `hero.pop("level")` | пара удалена |
| Перебрать | `d.items()`, `d.keys()`, `d.values()` | `for k, v in d.items():` | перебор |
| Объединить | `d1 \| d2` (3.9+), `d1.update(d2)` | `stock \| delivery` | новый или изменённый словарь |

## 8. Типичные ошибки

**Обращение к несуществующему ключу.** Правильно — `hero.get("wallet")`: вернёт `None`, а не упадёт.
<!-- no-check -->
```python
hero = {"name": "КиберКот"}
print(hero["wallet"])
```

```text
Traceback (most recent call last):
  File "main.py", line 2, in <module>
    print(hero["wallet"])
KeyError: 'wallet'
```

**Список в роли ключа.** Правильно — ключ-строка `{"меч и щит": 2}` или кортеж `{("меч", "щит"): 2}`.
<!-- no-check -->
```python
stock = {["меч", "щит"]: 2}
```

```text
Traceback (most recent call last):
  File "main.py", line 1, in <module>
    stock = {["меч", "щит"]: 2}
TypeError: cannot use 'list' as a dict key (unhashable type: 'list')
```

В более старых версиях Python текст короче: `TypeError: unhashable type: 'list'`. Список можно менять, а ключ должен быть неизменяемым: строка, число, кортеж.

**Путаница «ключ» и «значение».** `in` смотрит только ключи, а `10` — значение, поэтому ищем перебором.

```python
stock = {"яблоки": 10, "бананы": 5}
print("яблоки" in stock)
print(10 in stock)
print(10 in stock.values())
```

```text
True
False
True
```

**Тело цикла без отступа.** Правильно — `print(key)` с отступом 4 пробела от строки `for`.
<!-- no-check -->
```python
hero = {"strength": 85}
for key in hero:
print(key)
```

```text
  File "main.py", line 3
    print(key)
    ^
IndentationError: expected an indented block after 'for' statement on line 2
```

## 9. Практика

**Разминка. Профиль игрока.**
Создайте словарь с ключами `name`, `level`, `health`, `inventory` (список из двух предметов). Напечатайте имя и здоровье.
*Сделано, если* пар ровно четыре, а `inventory` — настоящий список.

**Основное. Скидка в магазине.**
Дан словарь `prices = {"яблоко": 50, "банан": 70, "молоко": 80}`. Напечатайте те же товары с ценами после скидки 10 %, целыми числами.
```text
яблоко: 45
банан: 63
молоко: 72
```
*Сделано, если* вывод совпал с примером построчно, а скидка считается внутри цикла.

**Основное. Учёт поставок на склад.**
Сложите остатки и поставку: одинаковые товары просуммируйте, новые добавьте. Условие, примеры ввода и критерии — в задаче [Учёт поставок на склад](../Задачки/007_2.md); функции из неё появятся в следующей статье, пока можно решить циклом.
*Сделано, если* бананы из примера стали `12`, а хлеб появился в конце.

**Со звёздочкой. Достижения.**
Создайте вложенный словарь с тремя достижениями (название, награда, получено). Напечатайте полученные и посчитайте сумму наград, затем добавьте четвёртое достижение.
*Сделано, если* сумма считается циклом по `values()`, а добавление не ломает остальные записи.

## 10. Проверь себя

<details>
<summary>Что выведет <code>print(d.get("x"))</code>, если ключа <code>x</code> нет?</summary>
<code>None</code>. А <code>print(d["x"])</code> в той же ситуации упадёт с <code>KeyError</code>.
</details>

<details>
<summary>Что выведет <code>print(len({"a": 1, "b": 2, "a": 3}))</code>?</summary>
<code>2</code>. Пара с ключом <code>a</code> одна, повторная запись затёрла значение на <code>3</code>.
</details>

<details>
<summary>Что вернёт <code>setdefault</code>, если ключ уже есть, и что выведет <code>{"a": 1} | {"a": 2, "b": 3}</code>?</summary>
<code>setdefault</code> вернёт текущее значение и ничего не изменит. Объединение даст <code>{'a': 2, 'b': 3}</code>: при совпадении ключей побеждает правое значение.
</details>

<details>
<summary>Почему <code>{[1, 2]: "x"}</code> не работает?</summary>
Список можно менять, поэтому словарю не на что опереться при поиске ключа. Такой объект называют нехешируемым: <code>TypeError: unhashable type: 'list'</code>.
</details>

## 11. Словарь терминов

| Термин | Что значит | По-английски |
|---|---|---|
| Словарь | Набор пар «ключ → значение» | Dictionary |
| Ключ | Название, по которому ищут значение | Key |
| Значение | Данные, лежащие под ключом | Value |
| Пара ключ-значение | Одна запись словаря | Key-value pair |
| Метод | Команда словаря: `get`, `items` | Method |
| Вложенный словарь | Словарь внутри словаря | Nested dictionary |
| Нехешируемый | Объект, который нельзя использовать как ключ | Unhashable |
