## 1. Вывод и ввод

`print()` показывает значения и сам ставит пробелы между аргументами. f-строка подставляет переменные в текст. `input()` задаёт вопрос и **всегда возвращает строку**, поэтому для числа нужен `int()`. Подробно — в [статье 001](001_Python_Начало.md).

```python
name = "Аня"
age = 12
print("Меня зовут", name, "и мне", age, "лет")
print(f"Меня зовут {name}, мне {age} лет")

count = int(input("Сколько раз повторить? "))   # ввод: 3
print("Повтор" * count)
```

```text
Меня зовут Аня и мне 12 лет
Меня зовут Аня, мне 12 лет
Сколько раз повторить? 3
ПовторПовторПовтор
```

## 2. Переменные и типы

Основные типы: `int` — целое, `float` — дробное, `str` — строка в кавычках, `bool` — `True` или `False`. Имена пишут латиницей, `=` кладёт значение в переменную, а `==` сравнивает. `type()` показывает тип. Подробно — в [статье 001](001_Python_Начало.md).

```python
score = 10
ratio = 1.5
name = "Аня"
is_ready = True

print(type(score).__name__, type(ratio).__name__)  # int float
print(int("42") + 1)   # 43
print(str(42) + "!")   # 42!
```

```text
int float
43
42!
```

## 3. Операции

`+`, `-`, `*`, `/` работают как в математике, причём `/` всегда даёт `float`. `//` — деление нацело, `%` — остаток, `**` — степень. Строки склеиваются через `+` и повторяются через `*`. Сравнения дают `True` или `False`. Подробно — в [статье 001](001_Python_Начало.md).

```python
x = 10
y = 3
print(x + y, x - y, x * y)       # 13 7 30
print(x / y, x // y, x % y)      # 3.3333333333333335 3 1
print(x ** 2, "ха" * 3)          # 100 хахаха
print(x > y, x == y)             # True False
```

```text
13 7 30
3.3333333333333335 3 1
100 хахаха
True False
```

## 4. Списки

Список — набор значений в квадратных скобках. Индексы начинаются с 0, отрицательный индекс считает с конца; срез `[1:3]` берёт элементы с 1 по 2. `append()` добавляет в конец, `insert()` — на позицию, `remove()` удаляет по значению, `pop()` — по индексу и возвращает элемент. `clear()` очищает список, но возвращает `None`, поэтому присваивать результат бессмысленно. Подробно — в [статье 005](005_Python_List.md).

```python
games = ["Minecraft", "Roblox", "Brawl Stars"]
games.append("Among Us")
games.insert(1, "Terraria")
print(games[0], games[-1])        # Minecraft Among Us

removed = games.pop(1)            # "Terraria"
games.remove("Roblox")            # удаляет по значению
print(games)                      # ['Minecraft', 'Brawl Stars', 'Among Us']
print(len(games), removed)        # 3 Terraria

products = ["хлеб", "молоко"]
products.clear()                  # очищает список, возвращает None
print(products)                   # []
```

```text
Minecraft Among Us
['Minecraft', 'Brawl Stars', 'Among Us']
3 Terraria
[]
```

## 5. Условия

`if` выполняет блок, когда условие истинно; `elif` проверяет следующий вариант, `else` срабатывает, если не подошло ничего. Сравнения: `==`, `!=`, `>`, `<`, `>=`, `<=`. Логика: `and` — оба условия, `or` — хотя бы одно, `not` — отрицание. Вместо `ticket == True` достаточно `if ticket:`. Тело условия — с отступом 4 пробела. Подробно — в [статье 002](002_Python_Условия.md).

```python
score = 4
if score == 5:
    print("Отлично")
elif score >= 4:
    print("Хорошо")
else:
    print("Надо подтянуть")

ticket = True
if ticket:
    print("Проходи в кинотеатр")
else:
    print("Купи билет")
```

```text
Хорошо
Проходи в кинотеатр
```

## 6. Циклы

`for` перебирает элементы последовательности, `range()` создаёт числа: `range(1, 11, 2)` — от 1 до 10 с шагом 2, правая граница не включается. `while` повторяет, пока условие истинно; внутри тела условие нужно менять, иначе цикл не закончится. `break` выходит из цикла, `continue` пропускает остаток шага. Подробно — в [статье 003](003_Python_Циклы.md).

```python
for number in range(1, 11, 2):
    print(number, end=" ")
print()

attempts = 0
while attempts < 3:
    attempts += 1
print(f"Попыток: {attempts}")

for number in range(10):
    if number == 3:
        break
    if number % 2 == 0:
        continue
    print(number)
```

```text
1 3 5 7 9 
Попыток: 3
1
```

## 7. Обработка ошибок

`try` выполняет код, `except` ловит ошибку и не даёт программе упасть. Ловить нужно конкретный тип: `except ValueError:` для неверного `int()`, голый `except:` скрывает настоящую причину. Файл открывают через `with open(...) as file:` — тогда он закроется сам, даже если внутри произошла ошибка. Отдельные статьи про ошибки и файлы пока только в [плане](../План_статей_по_Python.md) курса: здесь достаточно этого напоминания.

```python
try:
    age = int(input("Сколько тебе лет? "))
    print(f"Через год тебе будет {age + 1}")
except ValueError:
    print("Нужно вводить число, а не текст")
```

```text
Сколько тебе лет? двенадцать
Нужно вводить число, а не текст
```

```python
try:
    with open("data.txt", encoding="utf-8") as file:
        content = file.read()
    number = int(content)
    print(f"Число из файла: {number}")
except FileNotFoundError:
    print("Файл не найден")
except ValueError:
    print("В файле не число")
```

Если файла `data.txt` нет, сработает `FileNotFoundError` и напечатается «Файл не найден»; если в файле текст вместо числа — второй `except`.

## 8. Пример: игра Угадай число

Собирает всё сразу: `import random`, `while`, `if`, `try/except` и список; цикл и `break` подробно разобраны в [статье 003](003_Python_Циклы.md). Флаг `won` нужен, чтобы в конце не проверять `guess`: если игрок ни разу не ввёл число, переменной ещё нет и `guess != secret_number` даст `NameError`.

```python
import random

secret_number = random.randint(1, 100)
attempts = 0
max_attempts = 10
history = []
won = False

while attempts < max_attempts:
    attempts += 1
    try:
        guess = int(input(f"Попытка {attempts}/{max_attempts}: "))
    except ValueError:
        print("Вводи только числа!")
        continue

    history.append(guess)
    if guess < secret_number:
        print("Больше!")
    elif guess > secret_number:
        print("Меньше!")
    else:
        print(f"Победа! Понадобилось попыток: {attempts}")
        won = True
        break

if won:
    print(f"История: {history}")
else:
    print(f"Не угадал, число было: {secret_number}")
```

```text
Попытка 1/10: 50
Меньше!
Попытка 2/10: 42
Победа! Понадобилось попыток: 2
История: [50, 42]
```
