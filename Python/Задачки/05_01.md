# Определение типа треугольника

**Условие задачи:**

Напишите программу на Python, которая:

1. Запрашивает у пользователя ввод трех чисел (длины сторон треугольника)
2. Проверяет, можно ли построить треугольник с такими сторонами
3. Если треугольник возможен, определяет его тип:
   - Равносторонний: все три стороны равны
   - Равнобедренный: две стороны равны
   - Разносторонний: все стороны разные
4. Выводит тип треугольника

**Примеры работы программы:**

*Пример 1:*
```
Введите длину стороны 1: 3
Введите длину стороны 2: 4
Введите длину стороны 3: 5
Треугольник возможен. Тип: разносторонний
```

*Пример 2:*
```
Введите длину стороны 1: 5
Введите длину сторону 2: 5
Введите длину сторону 3: 5
Треугольник возможен. Тип: равносторонний
```

*Пример 3:*
```
Введите длину стороны 1: 4
Введите длину стороны 2: 4
Введите длину стороны 3: 6
Треугольник возможен. Тип: равнобедренный
```

*Пример 4:*
```
Введите длину стороны 1: 1
Введите длину стороны 2: 2
Введите длину стороны 3: 10
Треугольник невозможен (сумма двух меньших сторон меньше третьей)
```

**Примечание:**
Для проверки возможности треугольника используйте неравенство треугольника:
a + b > c, a + c > b, b + c > a
где a, b, c - длины сторон
