## Краткая выжимка

* **Список** — упорядоченный набор значений в квадратных скобках: `[1, "текст", 3.14]`
* **Индексы** начинаются с 0, `[-1]` — последний элемент, срез `a[1:3]` берёт элементы с индексами 1 и 2
* **append()** и **insert()** добавляют элемент в конец и на позицию
* **remove()** удаляет по значению, **pop()** — по индексу и возвращает элемент
* **enumerate()** даёт индекс и элемент одновременно
* **len**, **sum**, **max**, **min**, **in** — размер, сумма, максимум, минимум, проверка наличия

## 3. Список: создание, индексы и срезы

Если друзей трое, можно завести три переменные. А если их тридцать? Список хранит сколько угодно значений в одной переменной и сохраняет порядок; создаётся он квадратными скобками, а элементы разделяются запятой.

```python
friends = ["Аня", "Петя", "Маша", "Сергей"]
print(friends[0])        # Аня
print(friends[-1])       # Сергей
print(friends[1:3])      # ['Петя', 'Маша']
print(friends[::2])      # ['Аня', 'Маша']
```

Индексы начинаются с 0, отрицательные считают с конца, а срез берёт элементы до правой границы, не включая её. Третье число в срезе — шаг, поэтому `friends[::-1]` даёт копию в обратном порядке.

## 4. Методы списка

Метод — команда самого списка. Инвентарь героя — это список предметов, и методы его меняют: `append` добавляет в конец, `insert` — на позицию, `remove` удаляет первое совпадение по значению, `pop` — по индексу и возвращает элемент; `extend` добавляет элементы другого списка по одному, `reverse` разворачивает список, `sort` сортирует его на месте.

```python
inventory = ["меч", "щит"]
inventory.append("зелье")
inventory.insert(1, "лук")
print(inventory)        # ['меч', 'лук', 'щит', 'зелье']
inventory.remove("щит")
print(inventory.pop())  # зелье
print(inventory)        # ['меч', 'лук']
```

## 5. Перебор и enumerate

Цикл `for friend in friends` берёт элементы по одному, но не даёт номер. Индекс нужен, чтобы нумеровать элементы, обращаться к соседям или менять элемент по позиции; получить его можно через `range(len(...))` или `enumerate`.

```python
friends = ["Аня", "Петя", "Маша"]

for index in range(len(friends)):
    print(f"{index}: {friends[index]}")   # 0: Аня, 1: Петя, 2: Маша
for index, friend in enumerate(friends):
    print(f"{index + 1}. {friend}")       # 1. Аня, 2. Петя, 3. Маша
```

`enumerate` возвращает пары «индекс, элемент», поэтому не нужно писать `friends[index]`. Вызов `enumerate(friends, 1)` начнёт нумерацию с 1.

## 6. Длина, сумма, максимум и минимум

`len` — сколько элементов, `sum` — сумма чисел, `max` и `min` — наибольший и наименьший; среднее — это `sum / len`. `sum` работает только с числами, а `max` и `min` — и со строками, по алфавиту. У пустого списка `sum([])` равно 0, а `max([])` падает с `ValueError`, поэтому перед делением проверяйте `len`.

```python
grades = [5, 4, 3, 5, 4]
print(len(grades))                # 5
print(sum(grades))                # 21
print(max(grades))                # 5
print(min(grades))                # 3
print(sum(grades) / len(grades))  # 4.2
```

## 7. Оператор in и копирование списка

`in` проверяет, есть ли элемент, `not in` — что его нет. А `b = a` не копирует список: обе переменные смотрят на один и тот же список.

```python
inventory = ["меч", "щит"]
print("меч" in inventory)     # True
print("лук" in inventory)     # False
a = [1, 2, 3]
b = a
b.append(4)
c = a.copy()
c.append(5)
print(a)                      # [1, 2, 3, 4] — b и a — один список
print(c)                      # [1, 2, 3, 4, 5] — копия независима
```

Независимая копия — это `c = a.copy()` или `c = a[:]`. Копируются только верхние элементы: вложенные списки у копии и оригинала останутся общими.

## 8. Справочник

| Что | Как | Пример |
|---|---|---|
| Создание, элемент и срез | `[1, 2, 3]`, `a[i]`, `a[1:3]` | `friends[0]` |
| Длина и числа | `len(a)`, `sum(a)`, `max(a)`, `min(a)` | `max(grades)` |
| Добавить | `a.append(x)`, `a.insert(i, x)` | `a.append(4)` |
| Удалить | `a.remove(x)`, `a.pop(i)` | `last = a.pop()` |
| Дополнить и переставить | `a.extend(b)`, `a.reverse()`, `a.sort()` | `a.sort()` |
| Наличие и копия | `x in a`, `a.copy()`, `a[:]` | `b = a.copy()` |

## 9. Типичные ошибки

**Вышли за границы списка.** Индексы идут от 0 до `len - 1`; `friends[-4]` при трёх элементах даст ту же ошибку.
<!-- no-check -->
```python
friends = ["Аня", "Петя", "Маша"]
print(friends[10])
```

```text
Traceback (most recent call last):
  File "main.py", line 2, in <module>
    print(friends[10])
          ~~~~~~~^^^^
IndexError: list index out of range
```

**Удаляют несуществующий элемент.** `remove` ищет по значению; проверяйте `if "сыр" in products:`.
<!-- no-check -->
```python
products = ["яблоки", "бананы"]
products.remove("сыр")
```

```text
Traceback (most recent call last):
  File "main.py", line 2, in <module>
    products.remove("сыр")
    ~~~~~~~~~~~~~~~^^^^^^^
ValueError: list.remove(x): x not in list
```

**Меняют список во время перебора.** Элементы сдвигаются, и часть пропускается; перебирайте копию `numbers.copy()`.

```python
numbers = [1, 2, 3, 4]
for number in numbers:
    numbers.remove(number)
print(numbers)
```

```text
[2, 4]
```

**Тело цикла без отступа.** Правильно — сдвинуть `print` на 4 пробела.
<!-- no-check -->
```python
for friend in ["Аня", "Петя"]:
print(friend)
```

```text
  File "main.py", line 2
    print(friend)
    ^^^^^
IndentationError: expected an indented block after 'for' statement on line 1
```

## 11. Проверь себя

<details><summary>Что выведет <code>a[1:3]</code>, если <code>a = [10, 20, 30, 40]</code>?</summary>
<code>[20, 30]</code>: срез начинается с индекса 1 и не включает элемент с индексом 3.
</details>
<details><summary>Почему после <code>b = a; b.append(4)</code> меняется и список <code>a</code>?</summary>
<code>b = a</code> не копирует список, а даёт второе имя для того же объекта. Независимая копия — <code>a.copy()</code> или <code>a[:]</code>.
</details>
<details><summary>Чем <code>append</code> отличается от <code>extend</code>?</summary>
<code>append</code> добавляет аргумент одним элементом, даже если это список; <code>extend</code> добавляет элементы переданного списка по одному.
</details>
<details><summary>Что вернёт <code>enumerate(["Аня", "Петя"])</code>?</summary>
Пары «индекс, элемент»: <code>(0, "Аня")</code> и <code>(1, "Петя")</code>. В цикле их удобно распаковать: <code>for i, name in enumerate(...)</code>.
</details>

## 12. Словарь терминов

| Термин | Что значит | По-английски |

| Срез | Часть списка `[начало:конец]` | Slice |
