## Условие

На складе есть остатки товаров. Они хранятся в словаре, где ключ — название товара, а значение — количество на складе.

Напиши программу, которая:

1. Считывает текущие остатки.
2. Считывает поставку.
3. С помощью функции `merge_stock(stock, delivery)` получает новый словарь с обновлёнными остатками.
4. С помощью функции `print_stock(stock)` выводит итоговые остатки.

Функция `merge_stock(stock, delivery)` должна:

- принимать два словаря;
- складывать количества одинаковых товаров;
- добавлять товары, которых не было в остатках;
- возвращать новый словарь;
- не изменять исходные словари.

Функция `print_stock(stock)` должна выводить товары в формате:

```text
товар: количество
```

Порядок вывода: сначала товары в том порядке, в котором они были в исходных остатках, затем новые товары в порядке появления в поставке.

Формат ввода:

```text
N
товар количество
...
M
товар количество
...
```

`N` — количество товаров в остатках, `M` — количество товаров в поставке. Если `M = 0`, поставки нет.

### Примеры

**Пример 1:** обычная поставка с уже известным и новым товаром

```
3
яблоки 10
бананы 5
молоко 2
2
бананы 7
хлеб 4
```

```
яблоки: 10
бананы: 12
молоко: 2
хлеб: 4
```

Объяснение: бананы уже были на складе, поэтому количества сложились: `5 + 7 = 12`. Хлеба раньше не было, поэтому он добавился в конец.

---

**Пример 2:** пустая поставка

```
2
ручка 3
тетрадь 8
0
```

```
ручка: 3
тетрадь: 8
```

Объяснение: поставка пустая, поэтому остатки не изменились. Программа всё равно выводит исходные товары.

---

**Пример 3:** товар с нулевым остатком и несколько новых товаров

```
1
карандаш 0
3
карандаш 5
линейка 2
ластик 1
```

```
карандаш: 5
линейка: 2
ластик: 1
```

Объяснение: у карандаша был остаток `0`, после поставки стало `0 + 5 = 5`. Линейка и ластик новые, поэтому добавились после карандаша в порядке поставки.

## Критерии

1. Есть функция `merge_stock(stock, delivery)`, которая принимает два словаря и возвращает новый словарь.
2. Одинаковые товары суммируются, новые товары добавляются в результат.
3. Исходные словари `stock` и `delivery` не изменяются.
4. Есть функция `print_stock(stock)`, которая выводит товары в формате `товар: количество`.
5. Программа правильно считывает данные и выводит товары в нужном порядке: сначала старые, затем новые.
