# Проверка возможности покупки

## Разбор похожей задачи

Рассмотрим простую задачу: проверка, хватает ли денег на покупку.

```python
# Пример простой проверки
money = 500
price = 300

if money >= price:
    print("Можно купить")
else:
    print("Недостаточно денег")
```

**Как это работает:**
1. `if money >= price:` - проверяем, достаточно ли денег
2. Если условие истинно (`True`), выполняем код после `:` (строка 5)
3. Если условие ложно (`False`), переходим к `else:` (строка 7)
4. `else:` выполняется, когда условие в `if` не выполнено

**Ключевые моменты:**
- `if` проверяет условие
- `else` выполняется, если условие не выполнено
- Отступы (пробелы в начале строк) важны для определения блока кода

## Основная задача

**Условие задачи:**

Напишите программу на Python, которая:

1. Запрашивает у пользователя ввод трёх значений:
   - Количество денег у покупателя
   - Цена товара
   - Есть ли скидка (да/нет)
2. Если есть скидка, применяет скидку 20% к цене товара
3. Проверяет, хватает ли денег на покупку:
   - Если денег достаточно, выводит "Покупка совершена" и остаток денег
   - Если денег недостаточно, выводит "Недостаточно средств" и сколько не хватает
4. Если введено некорректное значение для скидки (не "да" и не "нет"), выводит сообщение об ошибке

**Примеры работы программы:**

*Пример 1 (без скидки, достаточно денег):*
```
Введите количество денег: 1000
Введите цену товара: 750
Есть ли скидка? (да/нет): нет
Покупка совершена. Остаток: 250
```

*Пример 2 (со скидкой, достаточно денег):*
```
Введите количество денег: 500
Введите цену товара: 600
Есть ли скидка? (да/нет): да
Цена со скидкой: 480
Покупка совершена. Остаток: 20
```

*Пример 3 (недостаточно денег):*
```
Введите количество денег: 300
Введите цену товара: 450
Есть ли скидка? (да/нет): нет
Недостаточно средств. Не хватает: 150
```

*Пример 4 (некорректный ввод скидки):*
```
Введите количество денег: 400
Введите цену товара: 300
Есть ли скидка? (да/нет): может быть
Ошибка: введите 'да' или 'нет'
```

*Пример 5 (со скидкой, всё равно недостаточно):*
```
Введите количество денег: 350
Введите цену товара: 400
Есть ли скидка? (да/нет): да
Цена со скидкой: 320
Покупка совершена. Остаток: 30
```

**Подсказки:**
1. Используйте `input()` для получения данных от пользователя
2. Преобразуйте числа с помощью `int()` или `float()`
3. Для проверки строки используйте `==` (например, `discount == "да"`)
4. Скидка 20% = цена * 0.8
5. Используйте вложенные условия: сначала проверьте корректность ввода скидки, затем примените скидку, затем проверьте возможность покупки
