## Краткая выжимка

* `import turtle` подключает модуль — без него команды не работают
* `forward(d)` и `backward(d)` двигают черепашку, `right(a)` и `left(a)` поворачивают
* квадрат — это цикл из четырёх повторов по 90°, треугольник — из трёх по 120°
* `penup()` и `pendown()` решают, оставляет ли черепашка след
* `color()` задаёт цвет и пера, и заливки; заливка — между `begin_fill()` и `end_fill()`
* `turtle.done()` оставляет окно открытым, `speed(0)` включает максимальную скорость

## Что нужно знать заранее

Понадобятся переменные из [первой статьи](001_Python_Начало.md) и циклы из статьи [«Циклы»](003_Python_Циклы.md): квадрат в Turtle — это ровно один цикл `for` на четыре повтора.

```python
count = 0
for step in range(4):
    count += 1
print(count)
```

```text
4
```

Внутри цикла будут стоять команды черепашки: две строки повторятся четыре раза — и получится квадрат.

> Не помнишь, как работает `for`? Вернись к [003](003_Python_Циклы.md) — это 10 минут.

## 3. Начало работы

**Turtle** — стандартная библиотека Python для рисования: по холсту ползёт виртуальная черепашка с пером и оставляет след. Устанавливать ничего не нужно, но Python должен быть собран с Tkinter — на обычной установке для Windows он есть.

```python
import turtle

turtle.forward(100)
turtle.right(90)
turtle.forward(100)
turtle.done()
```

В консоли вывода нет — результат виден в окне: черепашка нарисовала уголок из двух линий. `import turtle` подключает модуль, `turtle.done()` запускает цикл окна (это то же самое, что `turtle.mainloop()`): программа не завершается, пока окно не закроют.

## 4. Управление движением

По умолчанию черепашка стоит в центре холста, в точке `(0, 0)`, смотрит вправо и рисует при каждом движении.

* `forward(расстояние)` — пройти вперёд
* `backward(расстояние)` — пройти назад
* `right(угол)` — повернуть направо
* `left(угол)` — повернуть налево
* `goto(x, y)` — переместиться в точку с координатами
* `setheading(угол)` — задать направление: 0° — вправо, 90° — вверх

```python
import turtle

turtle.setheading(90)     # смотрим вверх
turtle.forward(80)
turtle.goto(0, 0)         # возвращаемся в центр
turtle.done()
```

`right(90)` и `left(90)` поворачивают на один и тот же угол, только в разные стороны, а `setheading(90)` не поворачивает, а сразу ставит направление «вверх».

## 5. Первые фигуры

Квадрат — это четыре одинаковых шага, поэтому его рисует цикл, а не восемь строк подряд.

```python
import turtle

for _ in range(4):
    turtle.forward(100)
    turtle.right(90)
turtle.done()
```

У равностороннего треугольника внутренний угол 60°, а черепашке нужен внешний угол поворота: 180° − 60° = 120°. Значит, тело цикла будет таким же, только повторов три, а `right(120)`. Круг рисуется одной командой — `turtle.circle(50)`: черепашка начинает с нижней точки окружности и идёт против часовой стрелки.

## 6. Настройки пера и цвета

* `color(цвет)` задаёт сразу и цвет пера, и цвет заливки; для раздельной настройки есть `pencolor(цвет)` и `fillcolor(цвет)`
* `pensize(толщина)` — толщина линии в пикселях
* `speed(скорость)` — от 1 (медленно) до 10 (быстро), `speed(0)` — максимальная скорость без анимации
* `begin_fill()` и `end_fill()` — команды вокруг контура: всё, что нарисовано между ними, заливается цветом заливки
* `shape("turtle")` меняет вид черепашки: есть `"arrow"`, `"turtle"`, `"circle"`, `"square"`, `"triangle"`, `"classic"`
* `hideturtle()` прячет черепашку, `showturtle()` возвращает её на экран

```python
import turtle

turtle.color("red")
turtle.begin_fill()
for _ in range(4):
    turtle.forward(100)
    turtle.right(90)
turtle.end_fill()
turtle.done()
```

`color("red")` покрасил и линию, и заливку, поэтому квадрат получился красным целиком. Если нужен, например, синий контур и жёлтая заливка, пишут `pencolor("blue")` и `fillcolor("yellow")`.

## 7. Поднятие и опускание пера

Иногда черепашку нужно перенести в новую точку, не оставляя линии. Для этого перо поднимают, а потом опускают обратно.

```python
import turtle

turtle.forward(100)      # первая линия
turtle.penup()
turtle.backward(50)      # двигаемся без следа
turtle.pendown()
turtle.forward(100)      # вторая линия
turtle.done()
```

Пока перо поднято, `forward`, `backward` и `goto` только перемещают черепашку. `pendown()` возвращает перо на холст — дальше любое движение снова рисует.

## 8. Интерактивность

Turtle умеет реагировать на клавиши и клики мыши. Сначала включают прослушивание событий командой `listen()`, потом привязывают функцию к клавише через `onkeypress()`.

```python
import turtle


def move_forward():
    turtle.forward(20)


turtle.listen()
turtle.onkeypress(move_forward, "Up")   # стрелка вверх
turtle.done()
```

Функция `move_forward` — это заготовка действия: она выполнится не сразу, а в момент нажатия стрелки. Имя клавиши пишут строкой: `"Up"`, `"Down"`, `"Left"`, `"Right"`, `"space"`.

## 9. Несколько черепашек

Для сложного рисунка можно создать несколько независимых черепашек: у каждой свой цвет, положение и перо.

```python
import turtle

t1 = turtle.Turtle()
t2 = turtle.Turtle()
t1.color("red")
t2.color("blue")
t1.forward(100)
t2.left(90)
t2.forward(100)
turtle.done()
```

`turtle.Turtle()` создаёт новую черепашку, и дальше команды вызывают у конкретного объекта: `t1.forward(100)`. Обычные команды вида `turtle.forward(...)` управляют стандартной черепашкой, которая появляется при импорте, а не `t1` и не `t2`.

## 10. Справочник

| Команда | Что делает | Пример |
|---|---|---|
| `forward(d)` | Пройти вперёд на `d` пикселей | `turtle.forward(100)` |
| `backward(d)` | Пройти назад на `d` пикселей | `turtle.backward(50)` |
| `right(a)` / `left(a)` | Повернуть направо или налево на `a` градусов | `turtle.right(90)` |
| `goto(x, y)` | Переместиться в точку `(x, y)` | `turtle.goto(0, 0)` |
| `setheading(a)` | Задать направление: 0 — вправо, 90 — вверх | `turtle.setheading(90)` |
| `circle(r)` | Нарисовать круг радиусом `r` | `turtle.circle(50)` |
| `penup()` / `pendown()` | Поднять или опустить перо | `turtle.penup()` |
| `color(c)` | Задать цвет пера и заливки | `turtle.color("red")` |
| `pensize(w)` | Задать толщину линии | `turtle.pensize(3)` |
| `speed(s)` | Скорость: 0 — максимум, 10 — быстро, 1 — медленно | `turtle.speed(0)` |
| `begin_fill()` / `end_fill()` | Начать и закончить заливку контура | `turtle.begin_fill()` |
| `shape(name)` | Сменить вид черепашки | `turtle.shape("turtle")` |
| `hideturtle()` / `showturtle()` | Скрыть или показать черепашку | `turtle.hideturtle()` |
| `done()` | Оставить окно открытым до закрытия | `turtle.done()` |
| `clear()` / `reset()` / `bye()` | Стереть рисунок; стереть и вернуть всё в начало; закрыть окно | `turtle.reset()` |

## 11. Типичные ошибки

**Забыли `import turtle`.** Имя модуля не появится само.

<!-- no-check -->
```python
turtle.forward(100)
turtle.right(90)
turtle.done()
```

```text
Traceback (most recent call last):
  File "main.py", line 1, in <module>
    turtle.forward(100)
    ^^^^^^
NameError: name 'turtle' is not defined. Did you mean: 'tuple'? Or did you forget to import 'turtle'?
```

Правильно: первая строка программы — `import turtle`.

**Нет `turtle.done()` — окно мгновенно закрывается.** Скрипт доходит до последней строки и завершается вместе с окном.

<!-- no-check -->
```python
import turtle
turtle.forward(100)
```

Правильно: последняя строка — `turtle.done()`. Она запускает `mainloop()` и держит окно открытым, пока его не закроют.

**Тело цикла без отступа.** Python не понимает, что относится к циклу.

<!-- no-check -->
```python
import turtle

for _ in range(4):
turtle.forward(100)
turtle.right(90)
turtle.done()
```

```text
  File "main.py", line 4
    turtle.forward(100)
    ^^^^^^
IndentationError: expected an indented block after 'for' statement on line 3
```

Правильно: обе команды внутри цикла пишутся с отступом 4 пробела.

**Перепутали `left`/`right` или градусы.** В квадрате поворот 90°, в треугольнике — 120°, а не 60°.

<!-- no-check -->
```python
import turtle

for _ in range(3):
    turtle.forward(100)
    turtle.right(90)      # для треугольника нужен 120
turtle.done()
```

Программа не падает, но треугольник не замыкается: за три поворота по 90° черепашка развернётся на 270° вместо 360°. Для равностороннего треугольника угол поворота считают как 180° − 60° = 120°. `left` и `right` — зеркальные команды, для симметричной фигуры направление обхода не важно.

**Забыли `penup()`/`pendown()` — лишние линии.** Перо остаётся опущенным, и любой перенос рисует след.

<!-- no-check -->
```python
import turtle

for _ in range(4):
    turtle.forward(60)
    turtle.right(90)

turtle.forward(40)        # перо не подняли — лишняя линия
for _ in range(4):
    turtle.forward(60)
    turtle.right(90)
turtle.done()
```

Правильно: перед переносом — `turtle.penup()`, перед рисованием — `turtle.pendown()`. Если между фигурами появилась диагональ, почти всегда виновато опущенное перо.

## 13. Проверь себя

<details>
<summary>Что произойдёт, если вызвать <code>penup()</code> и не вернуть <code>pendown()</code>?</summary>
Черепашка будет двигаться без следа: перо поднято, поэтому <code>forward</code> и <code>goto</code> только перемещают её по холсту.
</details>

<details>
<summary>Почему окно закрывается сразу после запуска?</summary>
Программа дошла до конца и завершилась, а вместе с ней закрылось окно Turtle. Нужна последняя строка <code>turtle.done()</code> — она запускает <code>mainloop()</code> и ждёт закрытия окна.
</details>

<details>
<summary>Сколько градусов поворота нужно для равностороннего треугольника?</summary>
120°, а не 60°. 60° — внутренний угол треугольника, а черепашка поворачивает на внешний: 180° − 60° = 120°.
</details>

<details>
<summary>Чем <code>color("red")</code> отличается от <code>fillcolor("red")</code>?</summary>
<code>color</code> задаёт и цвет пера, и цвет заливки, а <code>fillcolor</code> — только заливку, линия остаётся прежней.
</details>

<details>
<summary>Что значит <code>speed(0)</code>?</summary>
Максимальную скорость: анимация отключается, и рисунок появляется почти сразу. Обычные значения — от 1 (медленно) до 10 (быстро).
</details>
