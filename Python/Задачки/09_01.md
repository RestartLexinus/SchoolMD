# Сумма чисел в диапазоне

## Разбор похожей задачи

Рассмотрим простую задачу: вывод чисел от 1 до 5 с помощью цикла `while`.

```python
# Пример простого цикла while
number = 1
while number <= 5:
    print(number)
    number = number + 1
```

**Вывод:**
```
1
2
3
4
5
```

**Как это работает:**
1. `number = 1` - инициализация переменной-счётчика
2. `while number <= 5:` - цикл выполняется пока условие истинно (`True`)
3. `print(number)` - выводит текущее значение
4. `number = number + 1` - увеличивает счётчик на 1 (важно для избежания бесконечного цикла!)
5. Цикл повторяется пока `number <= 5`

**Важные моменты о `while`:**
- Цикл выполняется ПОКА условие истинно
- Не забудьте обновлять переменную в условии внутри цикла
- Без обновления переменной цикл станет бесконечным
- Можно использовать `break` для досрочного выхода из цикла

## Основная задача

**Условие задачи:**

Напишите программу на Python, которая:

1. Запрашивает у пользователя два числа: начало и конец диапазона (целые числа)
2. Используя цикл `while`, вычисляет:
   - Сумму всех чисел в диапазоне
   - Сумму чётных чисел в диапазоне
   - Сумму нечётных чисел в диапазоне
   - Количество чисел в диапазоне
3. Выводит все вычисленные значения

**Примеры работы программы:**

*Пример 1:*
```
Введите начало диапазона: 1
Введите конец диапазона: 10

Результаты для диапазона 1-10:
Всего чисел: 10
Сумма всех чисел: 55
Сумма чётных чисел: 30
Сумма нечётных чисел: 25
```

*Пример 2:*
```
Введите начало диапазона: 5
Введите конец диапазона: 15

Результаты для диапазона 5-15:
Всего чисел: 11
Сумма всех чисел: 110
Сумма чётных чисел: 50
Сумма нечётных чисел: 60
```

*Пример 3 (обратный диапазон):*
```
Введите начало диапазона: 10
Введите конец диапазона: 1

Результаты для диапазона 10-1:
Всего чисел: 10
Сумма всех чисел: 55
Сумма чётных чисел: 30
Сумма нечётных чисел: 25
```

*Пример 4 (одинаковые числа):*
```
Введите начало диапазона: 7
Введите конец диапазона: 7

Результаты для диапазона 7-7:
Всего чисел: 1
Сумма всех чисел: 7
Сумма чётных чисел: 0
Сумма нечётных чисел: 7
```

**Подсказки:**
1. Используйте `while current <= end:` для цикла
2. Для обработки обратного диапазона (когда начало больше конца), поменяйте местами значения
3. Используйте оператор `%` для проверки чётности: `number % 2 == 0` - чётное
4. Создайте переменные-счётчики перед циклом и обновляйте их внутри цикла
5. Не забудьте увеличивать текущее значение на каждой итерации цикла

**Дополнительное задание:**
Добавьте вычисление:
- Среднего арифметического всех чисел
- Среднего чётных чисел  
- Среднего нечётных чисел
- Максимального и минимального числа в диапазоне
