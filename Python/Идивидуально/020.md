
## Разбор задачи «Повтор до победы»

### Условие задачи

Создайте тренажёр, который задаёт вопрос и повторяет его, пока не получит правильный ответ. Программа должна:

1. Объяснить правила.
2. Задать один вопрос по основам Python.
3. Циклически повторять запрос, если ответ неверен.
4. После правильного ответа поздравить и показать количество попыток.

**Пример работы:**

```
=== ТРЕНАЖЁР ===
Отвечайте, пока не получится верно!

Вопрос:
Чем заканчивается строка с условием if?
Ваш ответ: end

🤔 Нет.
Попробуйте снова...

Ваш ответ: :

✅ Отлично! Вы справились за 2 попытки!
```

**Требования:**

- Использовать `while` с выходом только при верном ответе.
- Считать и выводить количество попыток.

---

### Анализ задачи

Что нужно сделать? Мы должны организовать диалог с пользователем:

1. Вывести приветствие и правила.
2. Задать вопрос (он фиксирован, например, «Чем заканчивается строка с условием if?»).
3. Бесконечно запрашивать ответ, пока он не совпадёт с эталонным (в нашем случае правильный ответ — `:`).
4. При каждом неверном ответе увеличивать счётчик попыток и давать подсказку (или просто сообщать об ошибке).
5. При верном ответе завершить цикл, поздравить и показать общее число попыток.

Здесь идеально подходит цикл `while`, потому что мы не знаем заранее, сколько раз пользователь будет ошибаться. Цикл должен выполняться, пока условие «ответ неверен» истинно. Как только условие станет ложным (ответ правильный), цикл завершится.

### Алгоритм

1. Инициализируем переменную `attempts = 0` (счётчик попыток).
2. Задаём правильный ответ, например `correct = ":"`.
3. Выводим правила.
4. Запускаем бесконечный цикл `while True` (или `while answer != correct`).
5. Внутри цикла:
   - Запрашиваем ответ пользователя.
   - Увеличиваем `attempts` на 1.
   - Если ответ совпадает с правильным, выводим поздравление и количество попыток, затем `break` (выход из цикла).
   - Иначе выводим сообщение об ошибке и продолжаем цикл.

### Код с пояснениями

```python
# Тренажёр "Повтор до победы"

print("=== ТРЕНАЖЁР ===")
print("Отвечайте, пока не получится верно!\n")

correct_answer = ":"  # правильный ответ
attempts = 0          # счётчик попыток

while True:
    # Задаём вопрос
    print("Вопрос:")
    print("Чем заканчивается строка с условием if?")
    user_input = input("Ваш ответ: ").strip()  # убираем лишние пробелы
    
    attempts += 1  # увеличиваем счётчик
    
    if user_input == correct_answer:
        # Правильный ответ – выходим из цикла
        print(f"\n✅ Отлично! Вы справились за {attempts} попыток!")
        break
    else:
        # Неправильный ответ – продолжаем
        print("\n🤔 Нет.")
        print("Попробуйте снова...\n")
```

**Пояснение ключевых моментов:**

- `while True` — бесконечный цикл. Выход из него осуществляется только с помощью `break` при правильном ответе.
- `input()` получает строку от пользователя. Метод `.strip()` удаляет пробелы в начале и конце, чтобы случайные пробелы не считались ошибкой.
- Счётчик `attempts` увеличивается на каждой итерации, независимо от правильности, потому что каждый ввод считается попыткой.
- При правильном ответе мы выводим сообщение и прерываем цикл.

Этот код полностью соответствует условию и демонстрирует классическое применение цикла `while` для проверки ввода.

### Задание 1. «Сумматор»

**Условие:**  
Программа просит пользователя вводить целые числа (положительные, отрицательные или ноль). Ввод продолжается до тех пор, пока не будет введено число `0`. После окончания ввода программа выводит:

- Сумму всех введённых чисел (без учёта завершающего нуля).
- Количество введённых чисел (также без учёта нуля).

**Требования:**

- Использовать цикл `while`.
- Не использовать списки (можно обойтись переменными-аккумуляторами).
- Вывести итоговую сумму и количество.

**Пример:**

```
Введите число (0 для завершения): 5
Введите число (0 для завершения): -3
Введите число (0 для завершения): 10
Введите число (0 для завершения): 0
Сумма чисел: 12
Количество чисел: 3
```

##### Подсказка

Вам понадобятся две переменные: одна для суммы (`total`), другая для количества (`count`). В цикле читайте числа, пока не встретите `0`. При каждом числе, не равном нулю, прибавляйте его к сумме и увеличивайте счётчик на 1. Когда введут `0` — выходите из цикла и выводите результаты.

### Задание 2. «Угадай число»

**Условие:**  
Программа загадывает случайное целое число от 1 до 10 (включительно). Пользователь должен угадать его. После каждой попытки программа сообщает, больше или меньше загаданное число, чем введённое. Цикл продолжается, пока пользователь не угадает. В конце выведите количество попыток.

**Требования:**

- Использовать модуль `random` для генерации числа.
- Использовать цикл `while`.
- Подсказывать «Больше» или «Меньше».

**Пример:**

```
Я загадал число от 1 до 10. Попробуй угадать!
Твой вариант: 5
Меньше!
Твой вариант: 3
Больше!
Твой вариант: 4
Поздравляю! Ты угадал с 3-й попытки!
```

##### Подсказка

Вам понадобится модуль `random`. Чтобы получить целое число от 1 до 10, используйте:

```python
import random
secret = random.randint(1, 10)
```

Это всё, что нужно для «загадывания». Дальше организуйте цикл, в котором пользователь вводит число, вы сравниваете с `secret` и даёте подсказки «Больше» или «Меньше». Не забудьте счётчик попыток.
