# Задача: случайные числа и среднее значение

## Условие

Напишите программу на Python, которая:

1. Генерирует **10 случайных чисел** в диапазоне от **1 до 100**.
2. Выводит эти числа на экран.
3. Вычисляет и выводит их **среднее арифметическое**.

## Разбор задачи

Разобьём задачу на шаги:

1. **Подключить модуль `random`** — он нужен для генерации случайных чисел.
2. **Завести переменную `total` для накопления суммы** — изначально она равна `0`.
3. **Запустить цикл `for` на 10 повторений** — в каждой итерации:
   - сгенерировать одно случайное число с помощью `random.randint(1, 100)`;
   - вывести его на экран;
   - добавить его к переменной `total`.
4. **После цикла разделить сумму на 10** (количество чисел) — получим среднее значение.
5. **Вывести среднее значение** на экран.

## Пример решения

```python
import random

total = 0
N = 10  # количество чисел

print("Случайные числа:")

# Цикл: генерируем числа по одному и копим сумму
for _ in range(N):
    num = random.randint(1, 100)
    print(num)
    total += num

# Среднее = сумма / количество
average = total / N
print("Среднее значение:", average)
```

### Пример вывода

```

12

Среднее значение: 49.9
```

> Примечание: значения будут **разными** при каждом запуске, потому что числа генерируются случайно.

## Похожая задача (для самостоятельного решения)

Напишите программу на Python, которая:

1. Генерирует **15 случайных чисел** в диапазоне от **-50 до 50**.
2. Выводит эти числа на экран.
3. Выводит на экран **максимальное** и **минимальное** число из сгенерированных.
4. Выводит **сумму только положительных** чисел.

*Подсказка: решайте так же через цикл, без списков. Для максимума и минимума заведите переменные и обновляйте их в каждой итерации, сравнивая с текущим числом (`if num > maximum`). Для суммы положительных заведите переменную и добавляйте к ней число только когда `num > 0`.*
