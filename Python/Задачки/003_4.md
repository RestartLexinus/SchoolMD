# Задача: Сумма, кратная 39

**Тема:** Циклы while, остаток от деления · **Сложность:** средняя

## Условие

Программа по очереди спрашивает у пользователя целые числа и складывает их в общую сумму.

Правила работы:

1. Ввод продолжается до тех пор, пока **сумма всех введённых чисел не станет кратна 39** (то есть делится на 39 без остатка).
2. Если пользователь вводит `0` — программа сразу завершается, и этот `0` **не добавляется** к сумме.
3. Как только сумма стала кратна 39 — нужно вывести сумму и сообщение об успехе, а затем завершить программу.

### Пример 1: сумма стала кратна 39

```
Введите число: 5
Введите число: 10
Введите число: 24
Сумма 39 делится на 39! 🎉
```

### Пример 2: пользователь ввёл 0

```
Введите число: 7
Введите число: 12
Введите число: 0
Программа остановлена. Итоговая сумма: 19
```

### Критерии

1. Программа запрашивает числа в цикле, а не один раз.
2. Сумма накапливается в отдельной переменной.
3. Ввод `0` завершает программу, и `0` не попадает в сумму.
4. Кратность проверяется через остаток от деления: `сумма % 39 == 0`.
5. При успехе выводится сумма и сообщение, программа завершается.

## Подсказки

<details>
<summary>Подсказка 1. С чего начать</summary>

Заведи переменную `total = 0` — в ней будет копиться сумма. Дальше нужен бесконечный цикл `while True:`, внутри которого ты спрашиваешь число и решаешь, что с ним делать.

</details>

<details>
<summary>Подсказка 2. Порядок проверок внутри цикла</summary>

Сначала проверь, не ввёл ли пользователь `0` — если да, выведи итоговую сумму и сделай `break`. Только после этого добавляй число к сумме: `total += number`.

</details>

<details>
<summary>Подсказка 3. Как проверить кратность</summary>

Число делится на 39 без остатка, если `total % 39 == 0`. Эту проверку делай уже после того, как добавил очередное число. Не забудь, что при `total = 0` условие тоже истинно, поэтому проверять сумму нужно только после первого ввода.

</details>
