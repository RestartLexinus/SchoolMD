## Краткая выжимка

* **Функция** — именованный блок кода, который выполняют по вызову
* `def имя(параметры):` объявляет функцию, тело пишется с отступом 4 пробела
* **Параметр** — имя в скобках при объявлении, **аргумент** — значение при вызове
* Аргументы бывают позиционными (по порядку) и именованными (`city="Москва"`)
* `return` отдаёт результат вызывающему коду, `print` только показывает его на экране
* Функция без `return` возвращает `None`; локальные переменные снаружи не видны

## Что нужно знать заранее

Понадобятся словари из статьи [«Словари»](006_Python_Словари.md) и цикл `for` из [«Циклов»](003_Python_Циклы.md): функции часто принимают словарь или список и перебирают его.

```python
stock = {"яблоки": 10, "бананы": 5}
for product, count in stock.items():
    print(f"{product}: {count}")
```

```text
яблоки: 10
бананы: 5
```

> Не помнишь `dict.items()`? Вернись к [006](006_Python_Словари.md) — это 10 минут.

## 3. Зачем нужна функция

Нужен отчёт в рамке для понедельника и вторника. Логика одна, но одинаковые `print` приходится копировать и менять в них день — а потом исправлять сразу во всех копиях. **Функция** даёт повторяющемуся действию имя: логика записана один раз, а вызывают её сколько нужно раз с разными данными.

```python
day = "вторник"
print("=" * len(day))
print(day)
print("=" * len(day))
```

```text
=======
вторник
=======
```

Так выглядит код без функции — для каждого дня свой блок. Дальше соберём его в одну функцию.

## 4. def и вызов

Функцию объявляют словом `def` (от define — «определить»): имя, скобки с параметрами, двоеточие и тело с отступом. Объявление ничего не выполняет — код запускается только при вызове по имени.

```python
def show_report(day):
    print("=" * len(day))
    print(day)
    print("=" * len(day))

show_report("понедельник")
show_report("вторник")
```

```text
===========
понедельник
===========
=======
вторник
=======
```

Что произошло: вызов `show_report("понедельник")` подставил строку в параметр `day` и выполнил тело. Результат тот же, что при копировании, но рамку теперь правят в одном месте. Если объявить функцию и не вызвать, программа ничего не напечатает.

## 5. Параметры и аргументы

**Параметр** — имя в скобках при объявлении (`name`), **аргумент** — значение при вызове (`"Иван"`). Аргументы передают по порядку (позиционные) или с указанием имени (именованные), и тогда порядок не важен. Параметр без значения по умолчанию обязателен.

```python
def introduce(name, age, city):
    return f"{name}, {age} лет. Город: {city}"

def greet(name="гость"):
    return f"Привет, {name}!"

print(introduce("Мария", 25, "Москва"))
print(introduce(city="Санкт-Петербург", age=30, name="Алексей"))
print(greet())
```

```text
Мария, 25 лет. Город: Москва
Алексей, 30 лет. Город: Санкт-Петербург
Привет, гость!
```

У `greet` параметр `name` имеет значение по умолчанию `"гость"`, поэтому вызов без аргумента работает. У `introduce` значения по умолчанию нет: `introduce("Мария", 25)` упадёт с `TypeError` (пример в разделе ошибок). Функция ничего не печатает сама — она возвращает строку, а печатает её `print` снаружи.

## 6. return и print

Это главная путаница: `print` показывает значение на экране и выбрасывает его, а `return` отдаёт значение тому, кто вызвал функцию, — его можно сохранить и использовать дальше.

```python
def add(a, b):
    return a + b

def add_print(a, b):
    print(a + b)

result = add(2, 3)
print(f"Результат: {result}")
print(f"Удвоенный: {result * 2}")

nothing = add_print(2, 3)
print(f"А здесь: {nothing}")
```

```text
Результат: 5
Удвоенный: 10
5
А здесь: None
```

`add` вернула `5`, и с ним можно считать дальше: `result * 2`. `add_print` напечатала `5`, но вернула `None`: сохранять было нечего. Правило простое: значение нужно **использовать** — `return`, нужно только **показать** — `print`. Вернуть можно и несколько значений через запятую: `return minimum, maximum` — они придут кортежем.

## 7. None и области видимости

`None` — это «ничего», особое значение в Python; его возвращает любая функция без `return`, и проверяют его через `is None`. Переменные внутри функции живут только там.

```python
title = "Мой отчёт"

def make_greeting():
    text = "Привет"
    print(title)
    return text

print(make_greeting())
```

```text
Мой отчёт
Привет
```

Переменная `text` существует только пока выполняется функция: снаружи её нет, и `print(text)` после вызова упадёт с `NameError`. Глобальную `title` читать можно, но **менять чужие переменные не стоит**: правильнее вернуть новое значение через `return` и присвоить его снаружи — `score = add_bonus(score)`. Слово `global` оставьте на крайний случай: оно делает код запутанным.

## 8. Документация функции

Docstring — строка в тройных кавычках сразу после `def`. Она объясняет, что функция делает, и остаётся доступной через `.__doc__` и `help()`.

```python
def average(numbers):
    """Считает среднее арифметическое списка чисел."""
    return sum(numbers) / len(numbers)

print(average([4, 5, 6]))
print(average.__doc__)
```

```text
5.0
Считает среднее арифметическое списка чисел.
```

Docstring не обязателен для коротких функций, но если параметров много, одной строки хватает, чтобы через месяц понять смысл.

## 9. Дополнительно

Эти возможности пригодятся позже: на первый раз достаточно знать, что они есть, — раздел можно пропустить.

`*args` собирает все позиционные аргументы в кортеж, `**kwargs` — все именованные в словарь, `lambda` — короткая функция в одну строку.

```python
def total(*numbers):
    return sum(numbers)

def show_profile(**fields):
    for key, value in fields.items():
        print(f"{key}: {value}")

square = lambda x: x ** 2

print(total(1, 2, 3))
print(total(1, 2, 3, 4, 5))
show_profile(name="Иван", age=25)
print(square(5))
```

```text
6
15
name: Иван
age: 25
25
```

**Рекурсия** — вызов функцией самой себя. Обязателен базовый случай, иначе получится `RecursionError`.

```python
def countdown(n):
    if n == 0:
        print("Старт!")
        return
    print(n)
    countdown(n - 1)

countdown(3)
```

```text
3
2
1
Старт!
```

## 10. Справочник

| Что | Как | Пример | Результат |
|---|---|---|---|
| Объявить функцию | `def имя(параметры):` | `def add(a, b):` | функция создана |
| Вызвать функцию | `имя(аргументы)` | `add(2, 3)` | результат вызова |
| Вернуть значение | `return выражение` | `return a + b` | значение у вызывающего |
| Вернуть несколько | `return a, b` | `return minimum, maximum` | кортеж |
| Значение по умолчанию | `def f(x=10):` | `def greet(name="гость"):` | параметр необязателен |
| Позиционные аргументы | по порядку | `introduce("Мария", 25, "Москвы")` | порядок важен |
| Именованные аргументы | `имя=значение` | `introduce(city="Москвы", age=25)` | порядок не важен |
| Без `return` | функция вернёт `None` | `result = print("да")` | `None` |
| Проверить на `None` | `x is None` | `if result is None:` | `True` или `False` |
| Много позиционных | `*args` | `def total(*numbers):` | кортеж аргументов |
| Много именованных | `**kwargs` | `def show(**fields):` | словарь аргументов |
| Короткая функция | `lambda x: ...` | `square = lambda x: x ** 2` | функция `square` |
| Документация | строка после `def` | `average.__doc__` | текст docstring |

## 11. Типичные ошибки

**Забыли `return` — функция вернула `None`.** Правильно — `return x * 2`.
```python
def double(x):
    x * 2

print(double(5))
```

```text
None
```

**Вызвали функцию без скобок.** Правильно — `greet("Анна")`: скобки и запускают функцию.
```python
def greet(name):
    return f"Привет, {name}!"

result = greet
print(type(result))
```

```text
<class 'function'>
```

Без скобок в `result` лежит сама функция, а не её результат: `print(result)` показал бы `<function greet at 0x...>`, причём адрес при каждом запуске разный.

**Локальная переменная снаружи функции.** Правильно — вернуть значение через `return`.
<!-- no-check -->
```python
def make_greeting():
    result = "Привет"
    return result

make_greeting()
print(result)
```

```text
Traceback (most recent call last):
  File "main.py", line 6, in <module>
    print(result)
NameError: name 'result' is not defined
```

**Забыли аргумент.** Правильно — `greet("Анна")`.
<!-- no-check -->
```python
def greet(name):
    return f"Привет, {name}!"

print(greet())
```

```text
Traceback (most recent call last):
  File "main.py", line 4, in <module>
    print(greet())
TypeError: greet() missing 1 required positional argument: 'name'
```

**Тело функции без отступа.** Правильно — `return` с отступом 4 пробела от `def`.
<!-- no-check -->
```python
def greet(name):
return f"Привет, {name}!"
```

```text
  File "main.py", line 2
    return f"Привет, {name}!"
    ^
IndentationError: expected an indented block after function definition on line 1
```

## 12. Практика

**Разминка. Линия.**
Напишите функцию `line()`, которая печатает 10 минусов, и вызовите её три раза.
*Сделано, если* в выводе ровно три строки, а сами минусы записаны один раз — внутри функции.

**Основное. Скидка в магазине.**
Напишите функцию `apply_discount(prices, percent)`: она принимает словарь цен и размер скидки, возвращает **новый** словарь с новыми ценами и не меняет исходный.
Для `{"яблоко": 50, "банан": 70}` и скидки 10 % результат печатается так:
```text
яблоко: 45
банан: 63
```
*Сделано, если* исходный словарь не изменился, а результат возвращён через `return`, а не напечатан внутри функции.

**Со звёздочкой. Угадай число наоборот.**
Напишите игру, где компьютер загадывает число и иногда врёт в подсказках. Нужны минимум две функции: одна сравнивает числа, другая решает, соврать или нет. Условие и критерии — в задаче [«Угадай число наоборот»](../Задачки/007_1.md).
*Сделано, если* игра завершается после угадывания и в конце выводит число попыток и число обманов.

## 13. Проверь себя

<details>
<summary>Чем <code>print</code> отличается от <code>return</code>?</summary>
<code>print</code> показывает значение на экране и ничего не отдаёт, а <code>return</code> возвращает его вызывающему коду — значение можно сохранить и использовать дальше.
</details>

<details>
<summary>Что вернёт функция, в которой нет <code>return</code>, и что случится при вызове <code>greet()</code> без аргумента?</summary>
Функция без <code>return</code> вернёт <code>None</code>. Вызов без обязательного аргумента даст <code>TypeError: greet() missing 1 required positional argument: 'name'</code>.
</details>

<details>
<summary>Почему <code>result = greet</code> без скобок — ошибка?</summary>
Скобки запускают функцию. Без них в <code>result</code> попадёт сама функция, а не её результат: <code>type(result)</code> покажет <code>&lt;class 'function'&gt;</code>.
</details>

<details>
<summary>Почему переменную, созданную внутри функции, нельзя прочитать снаружи?</summary>
Она локальная и существует, только пока выполняется функция. Наружу значение передают через <code>return</code>.
</details>

## 14. Словарь терминов

| Термин | Что значит | По-английски |
|---|---|---|
| Функция | Именованный блок кода, который выполняют по вызову | Function |
| Объявление функции | Запись `def` с именем и телом | Definition |
| Вызов функции | Запуск функции по имени со скобками | Call |
| Параметр | Имя в скобках при объявлении | Parameter |
| Аргумент | Значение, переданное при вызове | Argument |
| Возвращаемое значение | Результат, который отдаёт `return` | Return value |
| Область видимости | Часть программы, где переменная доступна | Scope |
| Docstring | Строка документации сразу после `def` | Docstring |
| Рекурсия | Вызов функцией самой себя | Recursion |
