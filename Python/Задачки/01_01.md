# Калькулятор возраста

**Условие задачи:**

Напишите программу на Python, которая:

1. Запрашивает у пользователя ввод его года рождения
2. Вычисляет текущий возраст пользователя (предполагая текущий год 2026)
3. Выводит результат в формате: "Ваш возраст: [возраст] лет"

**Основные функции, которые нужно использовать:**

`print()` - выводит текст на экран
```python
print("Привет, мир!")
```

`input()` - получает ввод от пользователя
```python
name = input("Введите ваше имя: ")
```

`int()` - преобразует строку в целое число
```python
number_str = "25"
number_int = int(number_str)  # 25
```

**Подсказка:**
1. Используйте `input()` для получения года рождения (в виде строки)
2. Преобразуйте строку в число с помощью `int()`
3. Вычислите возраст: `2026 - год_рождения`
4. Используйте `print()` для вывода результата

**Пример работы программы:**

```
Введите ваш год рождения: 2000
Ваш возраст: 26 лет
```

**Пример с ошибкой ввода:**

```
Введите ваш год рождения: двадцать лет
Ошибка: введите число (например: 2005)
```

**Дополнительное пояснение:**

- `input()` всегда возвращает строку, даже если пользователь ввел число
- Для математических операций нужно преобразовать строку в число с помощью `int()`
- Можно использовать `try-except` для обработки ошибок, если введено не число
