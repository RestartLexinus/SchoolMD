## Краткая выжимка

* `print()` выводит текст на экран
* **Переменная** — имя, под которым хранится значение
* **str** — текст в кавычках, **int** — целое число, **float** — дробное
* `input()` задаёт вопрос и **всегда возвращает строку**
* `int(...)` превращает строку в число, `str(...)` — число в строку
* **f-строка** подставляет значения в текст: `f"Привет, {name}!"`

## Что нужно знать заранее

Это первая статья курса, поэтому вместо ссылок — короткий чек-лист:

* Python 3.10 или новее установлен: команда `python --version` печатает номер версии.
* Файл `.py` запускается командой `python hello.py` или через IDLE (`Win` → «IDLE»).
* Последняя строка ошибки в консоли называет её тип — с неё и начинай разбор.

Первая программа запускается за три шага:

```text
1. Создай файл hello.py и вставь в него код из следующего раздела.
2. Открой терминал в папке с файлом.
3. Выполни команду: python hello.py
```

## 3. Первая программа и переменные

```python
print("Привет, мир!")
print("Меня зовут Python")
```

```text
Привет, мир!
Меня зовут Python
```

`print()` — команда «покажи на экране». В скобках текст в кавычках или выражение: `print("3")` печатает текст, `print(3)` — число, `print(2 + 3)` — результат сложения. Строки с `#` — **комментарии**: Python их не выполняет, они для человека.

Переменная — коробка с наклейкой: в неё кладут значение, а на наклейке пишут имя, чтобы потом найти.

```python
game_title = "Майнкрафт"   # текст
player_score = 100         # число

print(game_title)
print(player_score + 50)
```

```text
Майнкрафт
150
```

Знак `=` — **присваивание**, а не «равно»: он кладёт значение справа в имя слева. Имя может начинаться с латинской буквы или `_`, содержит латинские буквы, цифры и `_`, без пробелов; регистр важен (`score` и `Score` — разные переменные). Имя лучше выбирать по смыслу: `player_score` понятнее, чем `x`.

## 4. Строки и числа

**str** (string) — строка: текст в одинарных или двойных кавычках. **int** (integer) — целое число, **float** — число с дробной частью, и дробную часть отделяет точка, а не запятая.

```python
name = "Алексей"
greeting = "Привет, " + name + "!"
laugh = "ха" * 3
a = 10
b = 3

print(greeting)
print(laugh)
print(a / b)
print(a // b)
print(a % b)
print(a ** b)
```

```text
Привет, Алексей!
хахаха
3.3333333333333335
3
1
1000
```

Что произошло: `+` склеивает строки (**конкатенация**), `*` повторяет строку. У чисел `+`, `-`, `*` работают как в математике, `/` всегда даёт `float`, `//` отбрасывает дробную часть, `%` возвращает остаток, `**` возводит в степень. `10 / 3` — это `3.3333333333333335`, а не `3`: деление не округляет.

## 5. input и преобразование типов

`input()` печатает вопрос, ждёт ответа и возвращает **строку** — даже если ввели число.

```python
name = input("Как тебя зовут? ")
age = int(input("Сколько тебе лет? "))
print(f"Привет, {name}! Через год тебе будет {age + 1} лет")

price = "199"
total = int(price) * 3
print("Итого: " + str(total) + " рублей")
```

```text
Как тебя зовут? Аня
Сколько тебе лет? 12
Привет, Аня! Через год тебе будет 13 лет
Итого: 597 рублей
```

Что произошло: `age = int(input(...))` сначала получает строку `"12"`, а `int()` превращает её в число, поэтому `age + 1` работает. Без `int()` строка и число не складываются — Python выдаёт `TypeError` (пример в разделе ошибок). `str(total)` делает обратное: превращает число в строку, чтобы приклеить его через `+`; в f-строке `str()` не нужен, она подставляет значения сама. Запись `{age + 1}` — выражение внутри f-строки.

## 6. Справочник

| Что | Как | Пример | Результат |
|---|---|---|---|
| Вывести текст | `print(...)` | `print("Привет")` | Привет |
| Задать переменную | `имя = значение` | `score = 10` | в `score` лежит 10 |
| Склеить и повторить строку | `+`, `*` | `"а" + "б"`, `"ха" * 3` | аб, хахаха |
| Спросить пользователя | `input("вопрос")` | `input("Имя? ")` | строка |
| Строка ↔ число | `int(...)`, `str(...)` | `int("100")`, `str(100)` | 100, "100" |
| Деление нацело, остаток, степень | `//`, `%`, `**` | `10 // 3`, `10 % 3`, `10 ** 3` | 3, 1, 1000 |
| Подставить в текст | f-строка | `f"счёт: {score}"` | счёт: 10 |

## 7. Типичные ошибки

**Опечатка в имени переменной.** Правильно — `print(player_score)`.
<!-- no-check -->
```python
player_score = 100
print(player_scor)
```

```text
Traceback (most recent call last):
  File "main.py", line 2, in <module>
    print(player_scor)
          ^^^^^^^^^^^
NameError: name 'player_scor' is not defined. Did you mean: 'player_score'?
```

**Сложение строки и числа.** Правильно — `print("Тебе " + str(age) + " лет")` или `print(f"Тебе {age} лет")`.
<!-- no-check -->
```python
age = 12
print("Тебе " + age + " лет")
```

```text
Traceback (most recent call last):
  File "main.py", line 2, in <module>
    print("Тебе " + age + " лет")
          ~~~~~~~~^~~~~
TypeError: can only concatenate str (not "int") to str
```

**Забыли закрывающую кавычку.** Правильно — `print("Привет, мир!")`.
<!-- no-check -->
```python
print("Привет, мир!)
```

```text
  File "main.py", line 1
    print("Привет, мир!)
          ^
SyntaxError: unterminated string literal (detected at line 1)
```

## 8. Практика

**Разминка. Визитка.** Заведи `name`, `city`, `age` и напечатай одной f-строкой: «Меня зовут Аня, я из Москвы, мне 12 лет». *Сделано, если* в коде нет `+`, а все три значения подставлены через `{}`.

**Основное. Калькулятор возраста.** Спроси год рождения и текущий год, посчитай возраст. *Сделано, если* оба числа получены через `int(input(...))`, а вывод — одна фраза с возрастом.
Готовая задача: [Калькулятор возраста](../Задачки/01_01.md).

**Основное. Чек в магазине.** Запроси цену и количество, посчитай сумму. *Сделано, если* вывод повторяет пример:
```text
Цена: 199
Итого: 597 рублей
```

**Со звёздочкой. Секунды в часы.** Переведи секунды в часы, минуты и секунды через `//` и `%`. *Сделано, если* для `3672` выводится `1 ч 1 мин 12 с`, а для `59` — `0 ч 0 мин 59 с`.

## 9. Проверь себя

<details><summary>Почему <code>input("Возраст: ")</code> возвращает строку, а не число?</summary>
<code>input</code> всегда возвращает текст: пользователь может ввести что угодно. Чтобы получить число, нужен <code>int(...)</code>.
</details>
<details><summary>Что выведет <code>print("3" + "4")</code> и что — <code>print(3 + 4)</code>?</summary>
Первое склеит строки и напечатает <code>34</code>, второе сложит числа и напечатает <code>7</code>.
</details>
<details><summary>Что напечатает код?</summary>
<pre>score = 10
score = score + 5
print(score)</pre>
<code>15</code>: справа вычисляется старое значение, потом записывается в <code>score</code>.
</details>
<details><summary>Зачем нужен <code>str(total)</code> в строке <code>"Итого: " + str(total)</code>?</summary>
Чтобы превратить число в строку: <code>+</code> соединяет только строки, иначе будет <code>TypeError</code>.
</details>
