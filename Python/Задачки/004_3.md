# Задача: N случайных чисел

## Условие

Пользователь вводит целое число `n` — сколько случайных чисел нужно вывести. Программа должна вывести ровно `n` случайных чисел в диапазоне от 1 до 1000, каждое с новой строки.

Требования:

1. Спросить у пользователя число `n`.
2. Если `n` меньше 1 — вывести сообщение `Количество чисел должно быть положительным` и завершиться, ничего не генерируя.
3. Иначе вывести ровно `n` случайных чисел от 1 до 1000, каждое с новой строки.

### Пример 1: n = 5

```
Введите количество чисел: 5
472
15
903
68
541
```

### Пример 2: n = 0

```
Введите количество чисел: 0
Количество чисел должно быть положительным
```

### Пример 3: n = 1

```
Введите количество чисел: 1
777
```

### Критерии

1. Количество чисел запрашивается у пользователя и преобразуется в целое число.
2. Числа генерируются через `random.randint(1, 1000)`.
3. Используется цикл, который выполняется ровно `n` раз.
4. Выводится ровно `n` чисел, каждое с новой строки.
5. При `n <= 0` выводится сообщение об ошибке, и программа завершается.

## Подсказки

<details>
<summary>Подсказка 1. Ввод количества</summary>

В начале программы подключи модуль `random`. Затем спроси количество чисел и преобразуй ответ в целое число: `n = int(input("Введите количество чисел: "))`.

</details>

<details>
<summary>Подсказка 2. Проверка числа</summary>

Если `n` меньше или равно нулю — выведи сообщение об ошибке. Удобно сделать так: `if n <= 0: print("...")`, а саму генерацию спрятать в `else:` — тогда при ошибке цикл вообще не запустится. Проверку делай **до** цикла, иначе он просто не выполнится, и будет непонятно, что произошло.

</details>

<details>
<summary>Подсказка 3. Цикл ровно n раз</summary>

Используй `for i in range(n):` — тело цикла выполнится ровно `n` раз. Внутри сгенерируй число `number = random.randint(1, 1000)` и сразу выведи его на экран.

`range(n)` даёт числа 0, 1, 2, …, n−1 — всего n штук. Само значение `i` в задаче не нужно, поэтому можно написать `for _ in range(n):`.

</details>
