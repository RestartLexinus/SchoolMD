# Красивые числа

## Подсказки перед началом

### 1. Остаток от деления (оператор `%`)

Оператор `%` возвращает остаток от деления одного числа на другое.

```python
# Примеры остатка от деления
print(10 % 3)  # 1 (10 делится на 3 три раза, остаток 1)
print(15 % 5)  # 0 (15 делится на 5 без остатка)
print(7 % 2)   # 1 (7 делится на 2 три раза, остаток 1)
```

**Проверка делимости:**
Если `число % делитель == 0`, то число делится без остатка

```python
# Проверка, делится ли число на 3
number = 9
if number % 3 == 0:
    print("Делится на 3")
```

### 2. Логические операторы `and` и `or`

**Оператор `and` (И)** - оба условия должны быть истинными:

```python
number = 21
# Оба условия должны быть True
if number % 2 == 0 and number % 9 == 0:
    print("Делится и на 2, и на 9")
```

**Оператор `or` (ИЛИ)** - хотя бы одно условие должно быть истинным:

```python
number = 15
# Достаточно одного условия True
if number % 2 == 0 or number % 9 == 0:
    print("Делится на 2 или на 9")
```

## Основная задача

**Условие задачи:**

Напишите программу на Python, которая:

1. Запрашивает у пользователя ввод целого числа
2. Определяет "красоту" числа по следующим правилам:
   - **"Красивое число"** - делится И на 3, И на 7
   - **"Слегка красивое число"** - делится на 3 ИЛИ на 7 (но не на оба)
   - **"Совсем не красивое число"** - не делится ни на 3, ни на 7
3. Выводит соответствующее сообщение

**Примеры работы программы:**

*Пример 1 (красивое число):*
```
Введите число: 21
Красивое число
```

*Пример 2 (слегка красивое - делится на 3):*
```
Введите число: 9
Слегка красивое число
```

*Пример 3 (слегка красивое - делится на 7):*
```
Введите число: 14
Слегка красивое число
```

*Пример 4 (совсем не красивое):*
```
Введите число: 10
Совсем не красивое число
```

*Пример 5 (красивое число):*
```
Введите число: 42
Красивое число
```

*Пример 6 (совсем не красивое):*
```
Введите число: 1
Совсем не красивое число
```

**Подсказки:**
1. Используйте `input()` для получения числа от пользователя
2. Преобразуйте строку в число с помощью `int()`
3. Сначала проверьте самое строгое условие (делится И на 3, И на 7)
4. Затем проверьте менее строгое условие (делится на 3 ИЛИ на 7)
5. Если ни одно условие не выполнено - число не красивое
6. Используйте конструкцию `if`, `elif`, `else` для проверки условий по порядку
