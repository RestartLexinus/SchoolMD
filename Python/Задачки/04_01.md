# Определение оценки по баллам

**Условие задачи:**

Напишите программу на Python, которая:

1. Запрашивает у пользователя ввод числа (количество баллов от 0 до 100)
2. Используя конструкцию `if-elif-else`, определяет оценку по следующей шкале:
   - 90 и выше: "Отлично" (A)
   - 80-89: "Хорошо" (B)  
   - 70-79: "Удовлетворительно" (C)
   - Менее 70: "Неудовлетворительно" (F)
3. Выводит соответствующую оценку
4. Если введенное число вне диапазона 0-100, выводит сообщение об ошибке

**Подсказка:**
- Используйте цепочку `if-elif-else` для проверки условий по порядку
- Начните проверку с самого высокого балла (90 и выше)
- Не забудьте проверить корректность ввода (0-100)

**Примеры работы программы:**

*Пример 1:*
```
Введите количество баллов (0-100): 95
Оценка: Отлично (A)
```

*Пример 2:*
```
Введите количество баллов (0-100): 82
Оценка: Хорошо (B)
```


*Пример 3:*
```
Введите количество баллов (0-100): 45
Оценка: Неудовлетворительно (F)
```

*Пример 4:*
```
Введите количество баллов (0-100): 105
Ошибка: Введите число от 0 до 100
```

**Дополнительное пояснение:**
Конструкция `if-elif-else` позволяет проверять несколько условий последовательно:
- `if` проверяет первое условие
- `elif` (сокращение от "else if") проверяет дополнительные условия  
- `else` выполняется, если ни одно из условий не выполнено
