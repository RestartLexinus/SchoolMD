# Монетка на Python: программа и задача

Сегодня учимся «бросать монетку» на Python. Списки нам не понадобятся: хватит `random.randint` и обычного `if`.

---

## Часть 1. Программа и её разбор

### Задача

Напишите программу, которая «бросает монетку» и выводит, что выпало. У пользователя ничего спрашивать не нужно — программа просто показывает результат.

Пример вывода:

```
Монетка подброшена. Выпал орёл
```

или

```
Монетка подброшена. Выпала решка
```

### Программа

```python
import random

number = random.randint(1, 2)

if number == 1:
    print("Монетка подброшена. Выпал орёл")
else:
    print("Монетка подброшена. Выпала решка")
```

### Разбор

1. **`import random`** — подключаем модуль случайных чисел. Без него Python не поймёт команду `random.randint`.

2. **`number = random.randint(1, 2)`** — «бросок». `randint(1, 2)` выдаёт целое число от 1 до 2 **включительно**, то есть либо `1`, либо `2`. Оба варианта выпадают с шансом 50%. Результат мы кладём в переменную `number` — она хранит одно число, никакой список не нужен.

3. **`if number == 1:`** — проверяем, что выпало. Если `1`, значит, «орёл».

4. **`print("Монетка подброшена. Выпал орёл")`** — выводим результат.

5. **`else:`** — сюда программа попадает, если выпало не `1`, то есть `2`. Значит, «решка», и мы выводим другую строчку.

### Что важно понять

- `randint(1, 2)` — это как подбросить монетку: два равных шанса.
- Каждый запуск программы — новый бросок. Результат не запоминается: если сейчас выпал орёл, в следующий раз снова 50 на 50.
- Мы храним **число**, а слово выбираем через `if/else`. Так проще, чем заводить список вариантов.

## Часть 2. Задача: угадай, что выпадет

### Условие

Напишите программу, которая:

1. **Сначала** спрашивает у пользователя, что выпадет: орёл или решка.
2. **Только потом** «бросает монетку» с помощью `random`.
3. Выводит, что выпало на самом деле.
4. Если пользователь угадал — выводит `Тебе повезло!`, иначе — `Не повезло`.

**Важно:** сначала ввод, только потом бросок. Иначе человек увидит результат и сможет схитрить. 😉 И списки не используйте — хватит `randint` и `if/else`.

**Пример (повезло):**

```
Что выпадет — орёл или решка? орёл
Монетка подброшена. Выпал орёл
Тебе повезло!
```

**Пример (не повезло):**

```
Что выпадет — орёл или решка? решка
Монетка подброшена. Выпал орёл
Не повезло
```

### Требования

1. Используется `random.randint(1, 2)`.
2. Спрашиваем пользователя **до** броска.
3. Программа показывает, что выпало: «Выпал орёл» или «Выпала решка».
4. При совпадении выводится `Тебе повезло!`, при несовпадении — `Не повезло`.
5. Регистр не должен мешать: `Орёл`, `орёл` и `орёл ` (с пробелом) — это один и тот же выбор.

### Подсказки

1. **Порядок строк.** Сначала `guess = input(...)`, и только после этого `number = random.randint(1, 2)`.

2. **Приведи ввод в порядок.** Сразу после `input` сделай так: `guess = input("...").strip().lower()`. Тогда лишние пробелы и большая буква не помешают сравнению.

3. **Сделай переменную `result`.** После броска заполни её словом — так же, как в части 1:

```python
if number == 1:
    result = "орёл"
else:
    result = "решка"
```

4. **Выведи результат.** Например, так: `print("Монетка подброшена. Выпал", result)`. Слово «выпал» подходит к орлу, а к решке — «выпала». Можно написать два разных `print` в ветках `if/else`.

5. **Сравни.** Осталось только проверить: `if guess == result:` — и вывести `Тебе повезло!` или `Не повезло`.
